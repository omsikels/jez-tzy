# Valentine's Day Coder Edition 💻💘

A fun and interactive Valentine's Day-themed website built with **HTML**, **CSS**, and **JavaScript**. The site features a playful animation where a **"No"** button moves around the screen, and the user can only click the **"Yes"** button. Perfect for showcasing your love with a unique, interactive twist!

---

## 🌟 Features

- **Interactive Button Animation**: The **"No"** button moves randomly within the screen, making it harder to click. Once the user clicks **"Yes"**, a love message is displayed.
- **Mobile-Friendly**: Optimized for mobile devices and responsive layouts.
- **No Button Escape**: The **"No"** button is constrained within the visible area and won't disappear or escape the screen.
- **Customizable**: Easy to customize background, images, and text.

💡 How It Works

1. HTML Structure:

Contains a heading, image, and two buttons (Yes and No).

The #playground div acts as the container with an invisible boundary that constrains the No button.

2. CSS Styling:

Full-screen gradient background with a responsive layout.

Buttons are positioned using position: fixed to ensure they remain visible on screen at all times.

Mobile-friendly design using media queries to adjust button sizes.

3. JavaScript Logic:

The No button moves randomly within the #playground container when hovered or touched.

The Yes button increases in size each time the No button is avoided.

On clicking Yes, a congratulatory message is displayed.

🎯 Features

No Button Movement: The No button randomly repositions itself within the visible screen area, making it difficult to click.

Button Growth: When the Yes button is clicked, it grows in size as a visual effect.

Responsive: The design automatically adjusts for different screen sizes, ensuring a pleasant experience on both desktops and mobile devices.
